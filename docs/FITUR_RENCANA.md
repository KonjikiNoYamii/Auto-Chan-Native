# Rencana Fitur Silica Assistant (Non-SSH)

Fitur untuk teman-teman yang tidak bisa pakai SSH.

## Prioritas 1 (High Value, Low Effort)
- [ ] **Alarm/Timer** — `AlarmManager`, command "pasang alarm jam 7 pagi", "timer 5 menit"
- [ ] **Catatan (Notes)** — Simpan/baca/hapus catatan via chat atau suara
- [ ] **Senter (Flashlight)** — Toggle via `CameraManager`, command "nyalakan senter"
- [ ] **Text-to-Speech (TTS)** — Waifu membaca balasan bubble dengan suara
- [ ] **Cuaca** — Fetch dari OpenWeatherMap, "gimana cuaca hari ini?"

## Prioritas 2
- [ ] **Kalkulator** — Operasi dasar via command atau dialog
- [ ] **WiFi / Data / DND toggle** — Command untuk kontrol konektivitas
- [ ] **Screenshot** — Ambil screenshot via command (mediaProjection sudah dideklarasi)

## Catatan
- Semua fitur harus kompatibel dengan overlay voice command
- TTS + Alarm jadi kombinasi paling impactful biar waifu makin hidup
